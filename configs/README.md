# Configuration Files

This directory contains configuration files for experiments.

## Structure

- `default.yaml`: Default configuration for all experiments
- `shot.yaml`: SHOT method specific configuration
- `tent.yaml`: TENT method specific configuration
- `nrc.yaml`: NRC method specific configuration
- `sar.yaml`: SAR method specific configuration

## Usage

```bash
python scripts/run_experiment.py --config configs/default.yaml
```
